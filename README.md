# NFA, DFA & NFA to DFA Conversion

## Overview

This project implements NFA, DFA, and NFA to DFA conversion using Python in Google Colab, with Graphviz for visualization.

### NFA
A Non-Deterministic Finite Automaton (NFA) can have multiple or no transitions for the same input symbol from a state.

### DFA
A Deterministic Finite Automaton (DFA) has exactly one transition for each input symbol from every state.

### NFA to DFA Conversion
An NFA can be converted into an equivalent DFA using the Subset Construction method, where each DFA state represents a set of NFA states.

This project demonstrates the practical implementation and visualization of finite automata and NFA-to-DFA conversion concepts in Automata and Compiler Design.
